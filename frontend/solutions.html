CORE FEATURES

One platform for health understanding.

HealthPulse brings health assessment, monitoring tools and machine learning prediction together in one simple platform.

01

Health Monitoring

Track important health indicators such as BMI, blood pressure, weight, physical activity, sleep and stress through simple interactive tools.

02

Health Assessment

Turn individual health measurements into easy-to-understand feedback that can help users become more aware of their health patterns.

03

ML Prediction

A trained Support Vector Machine model analyzes selected health features and provides a cardiovascular disease prediction for educational use.

MACHINE LEARNING

From health data to prediction.

HealthPulse uses a cardiovascular health dataset and a machine learning pipeline to process health information and generate a prediction.

The project uses a Support Vector Machine (SVM) classification model trained on cleaned health data. The model works with selected demographic, lifestyle and health measurements.

SIMPLE WORKFLOW

A clear path from input to insight.

The HealthPulse workflow keeps health data processing simple and understandable.

01

Input

Enter relevant health and lifestyle information through the HealthPulse interface.

02

Process

The backend receives the information and prepares the required features for the ML model.

03

Analyze

04

TECHNOLOGY

Built across three layers.

HealthPulse connects a simple frontend with a backend API and a machine learning prediction pipeline.

01

Frontend

HTML, CSS and JavaScript provide the interactive HealthPulse interface and health assessment tools.

02

Backend

FastAPI handles health prediction requests and connects the frontend with the machine learning model.

03

Machine Learning

A trained SVM classification model processes the health features and produces the prediction output.
