THE PROJECT

What is HealthPulse?

HealthPulse is a smart health monitoring and prediction system built using machine learning. It provides interactive tools for exploring common health indicators and a machine learning component for cardiovascular disease prediction.

The project brings together frontend development, backend API development, data processing and machine learning into one integrated system.

01

Monitor

Explore selected health indicators through interactive assessment tools.

02

Understand

Receive simple educational feedback from the available health assessments.

03

Predict

Use the trained machine learning model to generate a cardiovascular disease prediction.

PROJECT OBJECTIVE

Connecting health data with machine learning.

The goal of HealthPulse is to demonstrate how health-related data can be collected, processed and used within a machine learning workflow.

01

Collect

Capture selected demographic, health and lifestyle information through the interface.

02

Prepare

Process the input data into the features required by the machine learning model.

03

Analyze

Apply the trained SVM classification model to the prepared health features.

04

Present

Display the prediction result through the HealthPulse frontend.

MACHINE LEARNING

A trained model behind the prediction.

HealthPulse uses a cardiovascular health dataset for machine learning. After data cleaning and preparation, multiple classification models were evaluated.

The Support Vector Machine model was selected as the final model based on the evaluation approach used in the project.
