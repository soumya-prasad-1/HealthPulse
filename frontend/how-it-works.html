THE WORKFLOW

Four simple steps to generate an insight.

The HealthPulse prediction process moves health information through a clear and structured pipeline.

01

Enter Health Data

The user enters relevant information such as age, gender, height, weight, blood pressure, cholesterol, glucose and lifestyle factors.

02

Process Data

The backend receives the submitted information and prepares the required input features, including BMI.

03

Analyze with ML

The prepared health features are passed to the trained Support Vector Machine classification model.

04

Generate Prediction

The model returns a classification result that is displayed through the HealthPulse interface.

MACHINE LEARNING PIPELINE

Data moves through a complete pipeline.

The machine learning component is built around a cardiovascular health dataset. The data is cleaned, prepared and used to train a classification model.

HealthPulse currently uses a Support Vector Machine model for the final cardiovascular disease prediction.

SYSTEM ARCHITECTURE

Three layers working together.

HealthPulse connects the user interface, backend API and machine learning model into one workflow.

01

Frontend

HTML, CSS and JavaScript provide the user interface, health calculators and prediction form.

02

FastAPI Backend

FastAPI receives health data through the prediction API and sends the model result back to the frontend.

03

ML Model

The trained SVM model processes the prepared features and generates the final prediction.

DATA FLOW

A connected health workflow.

Each layer has a specific role in taking the user's health inputs and turning them into a model output.

01

User Interface

Health information is collected through the HealthPulse prediction form.

02

API Request

JavaScript sends the health information to the FastAPI prediction endpoint.

03

Model Inference

The backend passes the prepared features to the trained SVM model.

04

Result

The prediction response is returned and shown to the user on the HealthPulse interface.
